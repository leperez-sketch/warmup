# 🪢 EFL Tug of War - English Game

Un juego interactivo de tiro de cuerda para aprender inglés en clase o practicar en parejas, categorizado por niveles Marco Común Europeo (A1 - C1).

## 🚀 Pasos para subir este proyecto a GitHub Pages (Gratis)

1. **Descomprimir el archivo ZIP:**
   Extrae los 4 archivos (`index.html`, `styles.css`, `script.js`, `README.md`).

2. **Crear un repositorio en GitHub:**
   - Inicia sesión en [github.com](https://github.com).
   - Haz clic en `+` -> **New repository**.
   - Nombre: `efl-tug-of-war` (Público).

3. **Subir los archivos:**
   - Haz clic en **uploading an existing file**.
   - Arrastra los 4 archivos (`index.html`, `styles.css`, `script.js`, `README.md`).
   - Presiona **Commit changes**.

4. **Activar GitHub Pages:**
   - Ve a **Settings** -> **Pages**.
   - En *Branch*, selecciona `main` (o `master`) y carpeta `/root`.
   - Haz clic en **Save**.

5. **¡Listo!**
   Tu juego estará accesible públicamente en minutos.
